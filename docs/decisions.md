# 画面の決定の記録

画面の原則（CLAUDE.md）は「なぜ」だけを書く。ここには、その原則をどの画面で・どんな前提で・どの形にしたかを書く（stats2-course #247）。前提が変われば見直してよいのは、こちら。

関係図（まとまりの関係図・2つの概念のページ）の決定は、stats2-course の docs/relation-map-design.md 3 にある。

決定ごとに次を書く：

- **決定**：何をどうするか
- **原則**：どの原則から来たか（CLAUDE.md の番号）
- **前提**：どの画面・どの文脈で成り立つか
- **根拠**：渡辺さんの判断・iPhone の A/B・レビュー
- **日付**
- **見直す条件**：何が変わったら見直すか

## 印

### 印は2種類で、役目を分ける
- **決定**：
  - **分類の印**（確率分布・検定・推定など12種）：島の地図の島の名前、概念の印を取り寄せられないときの点に使う。遠目にどの分類かを見分ける。
  - **概念の印**（全129概念）：入口のライブラリ・概念のページ・地図の点・教科書で、その概念を示し、教科書とつなぐ。
    - 48×48・線 2.4。色は柱の色。分類ごとに形の系統をそろえる（推定は的・確率は円など）。形で描けない概念は記号を主にする。
    - 原本は教材の側（概念の `icon`）。画面は公開のデータの URL を CSS の mask で読む（SVG を本体に入れない。URL は登録した教材の場所の下だけ）。
    - 地図の点は Cytoscape の絵なので mask で塗れず、SVG を取り寄せて currentColor を柱の色に置き換える（src/termIcons.ts）。
    - 縮めたときの分類の見分けは、島の名前と柱の色に任せる。
- **原則**：8・19
- **前提**：教材の概念が129で、教科書と概念をつなぐ役目がある
- **根拠**：渡辺さん 2026-11-05（stats2-course #220。地図の点は「替える」。UI レビュー 18）。前の決定（2026-10-31「129語すべてに別の印は作らない」）は、印が地図の点で分類を見分けるだけだったころのもの
- **見直す条件**：概念の数が大きく増え、印を描き分けられなくなったとき

### 成立条件は区分ごとに、外れたときの説明と用語の札
- **決定**：
  - 概念のページ・関係のページの「成立条件」は同じ部品（src/Conditions.tsx）。区分のある教材では、要件・仮定・目安・データで確かめる手掛かりの順に見出しを分ける。
  - 見出しの横は区分の意味だけ（定義の条件・保証の条件・近似を勧める基準）。外れたときに何が言えなくなるかは行ごとの「外れたとき」に書く（同じ文を2か所に出さない）。仮定には「保証すること」、目安には対象と出典を添える。
  - 文に出る用語は、行の下に押せる札（44px）で並べ、押すとその概念を開く。押す先のない所では札にせず文字だけ。
  - 区分のない教材は、今までどおり式の条件・データの条件の2つの一覧。
  - 見出しの横の数は区分ごと（要件 1・仮定 1 など）。
  - 保証すること・外れたとき（目安なら対象と出典）が同じ行は1つの枠にまとめ、文を並べる（二項分布の4つの仮定で同じ説明を4回出さない。2026-11-08）。
- **原則**：4・7・6・12・8
- **前提**：教材が成立条件の区分（型の改訂38の conditions_detail）を書いた分類。stats2-course #249 の呼び名
- **根拠**：渡辺さん 2026-11-07・08（stats2-course #249 ①④。式を基準の定義にし、定義と「その分布に従う条件」を分ける）
- **見直す条件**：1つの概念の成立条件が10行を超え、区分の中でたたむ必要が出たとき

### 関係のタブの見出しは呼び名と向きで分ける
- **決定**：概念のページの関係のタブは、定義に使う概念・前提知識・前提・変換・対比・これを定義に使う概念・応用の見出しに分ける（使われる側のページは「これを定義に使う概念」）。見出しが種類を言っている行には札を重ねない。つながりの地図（RelMap）は4つの側のまま、側の名前は見出しの名前をつなげて出す
- **原則**：4・8・7
- **前提**：型の種類の名前（材料・前提）は v2 まで変えず、画面の言葉（src/kinds.tsx の kindName）だけを新しくする
- **根拠**：渡辺さん 2026-11-07（stats2-course #249 ④）
- **見直す条件**：つながりの地図を、関係の種類ごとの置き場所で描き直すとき（#249 のあと。渡辺さん 2026-11-07）


### ⑤ の種類は今の画面の種類に読み替える（M6 まで）
- **決定**：型 v2 の公開データの ⑤ の種類（定める・一種・特別な場合・移る・従う・同値・推定する・根拠・導ける・比べる）を、読み込みで今の画面の種類（材料・種類・一般化・変換・応用・導出・対比）に読み替えて描く（src/data.ts の SCREEN_KIND_OF_V2）。元の種類は kind_v2 に残し、札には ⑤ の名前を出す（特別な場合・従う など）
- **原則**：4（同じものはどの入口からも同じ見た目）・8
- **前提**：関係図・地図・学ぶ順の画面は v1 の種類で描く作りで、⑤ で描き直すのは stats2-course の M6（issue 270）
- **根拠**：渡辺さん 2026-11-09（stats2-course issue 289。確率分布を ⑤ に移した教材を公開するため）
- **見直す条件**：画面が ⑤ の種類のまま描けるようになったとき（M6）。そのとき読み替えを外す

### 一種の親は「何の一種か」、子は「この一種」
- **決定**：概念のページの関係のタブで、一種（今の画面では種類）の親は子のページの上の側に「何の一種か」の見出しで、子は親のページの下の側に「この一種」の見出しで出す。見出しが種類を言うので札は付けない
- **原則**：8（応用の側に落ちると「この先で使う」と読める）・17
- **前提**：親の定義は子の定義に入る（製本 ⑤ の包含）ので、定義に使う概念と同じ上の側に置く
- **根拠**：渡辺さん 2026-11-09（二項分布のページで確率分布が応用に出ていたスクリーンショットから）
- **見直す条件**：M6 で関係のタブを ⑤ の種類で組み直すとき
- **同じ考え方**：特別な場合（今の画面では一般化）も、特別な場合のページは上の側に「何の特別な場合か」、一般の側のページは下の側に「この特別な場合」（2026-11-09。幾何分布のページで負の二項分布が応用に出ていた）

### つながりの地図で、同じ相手の点は1つ
- **決定**：つながりの地図（RelMap）で、同じ相手に関係が2本以上（特別な場合と移る、移ると比べる など）あれば、点は1つにして、姿を変える → 比べる → 前 → 後 の順で先の側に置き、ほかの関係は札に並べる（「厳密・特別な場合」）。下の一覧には全部の行を残す。点の残らない側には見出しを出さない。札は線の真ん中ではなく、相手の点の手前に置く（右の点が1つなら点の上）
- **原則**：8（同じものを2か所に置かない）・6（札が中心の近くで重ならない）
- **前提**：製本 ⑤ の 7 で、包含＋移る・比べる＋ほか は同じ組に重ねてよい
- **根拠**：渡辺さん 2026-11-09（二項分布のページでベルヌーイ分布が2つ出ていたスクリーンショットから）
- **見直す条件**：同じ組の関係を1本の線の上で切り替えて見せる形を作るとき

### つながりの地図の1つの側は上限で畳む
- **決定**：つながりの地図の1つの側に置く点は、縦に並ぶ右と左は5つ、横に並ぶ上と下は6つまで。残りは側の見出しに「＋N」と添える（全部は下の一覧にある）。側の見出しは1行に収め（左右は13字・上下は26字まで）、長いときは最初の見出し＋「など」にする（2026-11-09。確率分布のページで見出しが地図をまたいで線に重なっていた）。右と左の5つは間を 31（点の高さ 30 より広く）にする
- **原則**：15・6
- **前提**：確率分布のページでは、一種の子・これを定義に使う概念・応用で左に10を超える点が並ぶ
- **根拠**：2026-11-09（確率分布に7つの分布の一種を足したとき、左の点が重なって読めなくなった）
- **見直す条件**：地図の大きさを変える・側を増やすとき
### 通す定理は定理の基準の定義で見せる
- **決定**：関係が通す定理（型 v2 の theorem。ベイズの定理・中心極限定理など）を持つとき、関係のページに「通す定理（定理の名前）」の段を置き、その定理の概念の基準の定義の文（要件を含む）を出す。定理の要件（ベイズの定理の P(D)＞0・P(H)＞0 など）は、関係の成立条件の段に写さない

- **前提**：教材が型 v2 で theorem と概念の basis.text を出す（stats2-course #297・#305。製本 ③ の 2「対象の要件は概念の側」）

### 長押しの手触り：沈んで光る
- **決定**：
  - 長押しのある所は全部、押さえている間に同じ手触りを出す：押した物がゆっくり沈み（0.92 倍まで）、縁が主の色で光っていく。満ちたところ（--dur-hold、450ms）で長押しが決まり、軽く振動する。途中で離すとふつうの「押した」。
  - ふつうのタップの間は見えないよう、押した返事（--dur-press）のあとから始める。指を動かしたら（地図を動かす）やめる。
  - 線は沈まず、太くなりながら光る。島の地図の点（Cytoscape）は、点の枠が主の色で太くなる。
  - 仕組みは math-lab の base.css の `data-hold`（見た目の物が子のときは `data-hold-part`）。新しく長押しを足すときも、これを付ける（tests/e2e/hold.spec.ts）。
  - 動きを減らす設定では沈まず、満ちたときに縁を一度灯すだけ。
- **原則**：10・13
- **前提**：長押しは見えない操作で、押さえている間に「長押しになる」と分からないと、離してよいか迷う
- **根拠**：渡辺さん 2026-11-07（戻るの長押しの見本 https://claude.ai/artifact/N4NgvkERR9KnRSJ5E9K5M4 で「3 沈んで光る」。「その他の長押しエフェクトにも統一が必要」）
- **見直す条件**：長押しの長さが合わない（早すぎて誤って出る・遅すぎて待たされる）と分かったとき

## 関係の種類の印

### ⑤ の種類のまま描き、印は数学の記号に寄せる
- **決定**：
  - 画面は ⑤ の種類（定める・一種・特別な場合・移る・同値・従う・推定する・導ける・根拠・比べる）と前提知識（学ぶ順の足す）をそのまま描く。v1 の種類への読み替え（src/screen-kinds.json の v2_to_screen）は同じ名前に写すだけにした（stats2-course #267 M7-1）。
  - 色は仲間で、今の5色のまま：灰＝定める・前提知識、青＝一種・特別な場合・導ける・根拠、オレンジ＝移る・同値・従う・推定する、赤紫＝比べる。従う・推定するに新しい色を足すと、今の色と色覚の違いで見分けにくかった（検査で落ちた）。
  - 印は種類ごとに1つで、数学の記号に寄せて線で描く：定める ≔・一種 ⊂・特別な場合 ｜（値を固定）・移る ↦・同値 ⇔・従う ～・推定する ^・導ける ⇒・根拠 ∵・比べる ≠・前提知識 →。字の記号は小さいと潰れるので、字では置かない（線の上の小さな記号だけは字）。
  - 分類の関係図の下の札（凡例を兼ねた絞り込み）は、その分類の線にある種類だけを並べ、1段に入らなければ2段に折り返す（全部の種類を並べると 390px からはみ出した。渡辺さん 2026-11-11 の iPhone のスクリーンショット）。
  - 概念のページの見出しは種類ごと（何の一種か／この一種、何に従うか／これに従うもの、何を推定するか／これを推定するもの、何から導けるか／これから導けるもの、何が根拠か／これを根拠にするもの など）。
