# 画面の決定の記録

画面の原則（CLAUDE.md）は「なぜ」だけを書く。ここには、その原則をどの画面で・どんな前提で・どの形にしたかを書く（stats2-course #247）。前提が変われば見直してよいのは、こちら。

関係図（まとまりの関係図・2つの概念のページ）の決定は、stats2-course の docs/relation-map-design.md 3 にある。

決定ごとに次を書く：

- **決定**：何をどうするか
- **原則**：どの原則から来たか（CLAUDE.md の番号）
- **前提**：どの画面・どの文脈で成り立つか
- **根拠**：渡辺さんの判断・iPhone の A/B・レビュー
- **日付**
- **見直す条件**：何が変わったら見直すか

## 印

### 印は2種類で、役目を分ける
- **決定**：
  - **分類の印**（確率分布・検定・推定など12種）：ライブラリの分類のタイルなど、概念の印を取り寄せられないときの点に使う。遠目にどの分類かを見分ける。
  - **概念の印**（全129概念）：入口のライブラリ・概念のページ・地図の点・教科書で、その概念を示し、教科書とつなぐ。
    - 48×48・線 2.4。色は柱の色。分類ごとに形の系統をそろえる（推定は的・確率は円など）。形で描けない概念は記号を主にする。
    - 原本は教材の側（概念の `icon`）。画面は公開のデータの URL を CSS の mask で読む（SVG を本体に入れない。URL は登録した教材の場所の下だけ）。
    - 地図は関係図（SVG と HTML）なので、地図の上の語の印も同じ mask で読む（島の地図の Cytoscape 用に SVG を取り寄せて塗り替える仕組みは、島の地図を外したとき（2026-11-24。stats2-course #588）に外した）。
- **原則**：8・19
- **前提**：教材の概念が129で、教科書と概念をつなぐ役目がある
- **根拠**：渡辺さん 2026-11-05（stats2-course #220。地図の点は「替える」。UI レビュー 18）。前の決定（2026-10-31「129語すべてに別の印は作らない」）は、印が地図の点で分類を見分けるだけだったころのもの
- **見直す条件**：概念の数が大きく増え、印を描き分けられなくなったとき

### 下のタブは印＋短い名前

## 地図

### 地図は関係図の1つ（島の地図を外した）
- **決定**：
  - 概念の地図は分類ごとの関係図だけにする。どの入口（検索・ライブラリの語・分類の一覧・Notion の 🕸 リンク `?c=`・つながりの札）から概念を開いても、その概念の分類の関係図で、その語を選んだ状態で開く。
  - 「まわり／たどる／全体」の切り替えと、島の地図（Cytoscape）・全部の概念の地図（`?g=*`）を外した。`?g=*` と `?view=all` の古い URL は、ライブラリ・関係図で開く。
  - 分類をまたぐ学ぶ順は、概念のページの「関係」の先頭の「前提をさかのぼる」から、全画面の一覧で読む（遠い前提から学ぶ順。行ごとに分類と「つまり」を添える。分類で区切ると、学ぶ順が分類を行き来するので見出しがほぼ1行ごとに並んだ）。`?view=path` で開く。
  - 埋め込み（`embed=1`。Notion の 360×320）は入口の札1枚（名前・つまり・拡大表示）。地図は大きく開いた先の関係図で見る。
  - 概念を選んでいる間は、どの幅でも関係図が画面いっぱいになり、詳しくは下からの面で出す（広い画面で面にしないと、詳しくが関係図の後ろに隠れた）。
  - 現在地：語を選んで上の帯（パンくず・並べ方の切り替え）が引っ込んでいる間は、地図の左上に分類の印と分類名を出す。押すと分類のページ（正方形・一覧・地図）へ戻る。1つ前の概念へ戻る ‹ はその下（印を分ける）。下のタブには現在地を出さない（下は学ぶ操作の行き先。原則 17）。渡辺さん 2026-11-24「1で」
- **原則**：4（同じものはどの入口からも同じ見た目）・8・20（読むときは全画面のページ）・3
- **前提**：教材の全分類を関係図に移した（stats2-course #589。2026-11-23）。関係図は1つの分類の横のつながり（製本 ⑤）、前提をさかのぼるは分類をまたぐ学ぶ順（製本 ⑥）で、答える問いが違う（二項分布の前提 16 のうち 13 はほかの分類）
- **根拠**：渡辺さん 2026-11-23（stats2-course #587「この画面は廃止し、こちらに一本化させたい」、たどるの置き場の案）・2026-11-24「完成まで進めて」
- **見直す条件**：関係図の中で前提を一時的に線で見せる「前提を見る」の札（設計書の入れる順 6）が要ると分かったとき。教材が2つ以上になり、分類をまたいで地図を見たくなったとき

## 読むページ

### 全画面のページの骨組み
- **決定**：
  - 中身を読む・つながりを開くときは、実験室と同じ骨組みにする：上に「←・題」、中は指で送る、下に次の1手。
  - ← は1つ前（つながり → 概念 → 地図）へ戻る。
  - 選んだものは色と太さで示す。拡大する・点滅させる動きは使わない。
- **原則**：20・3・10
- **前提**：iPhone の幅。地図の上の面は探すためのもの
- **根拠**：渡辺さん 2026-11-04（stats2-course #188 07・#194）

### 成立条件は区分ごとに、外れたときの説明と用語の札
- **決定**：
  - 概念のページ・関係のページの「成立条件」は同じ部品（src/Conditions.tsx）。区分のある教材では、要件・仮定・目安・データで確かめる手掛かりの順に見出しを分ける。
  - 見出しの横は区分の意味だけ（定義の条件・保証の条件・近似を勧める基準）。外れたときに何が言えなくなるかは行ごとの「外れたとき」に書く（同じ文を2か所に出さない）。仮定には「保証すること」、目安には対象と出典を添える。
  - 文に出る用語は、行の下に押せる札（44px）で並べ、押すとその概念を開く。押す先のない所では札にせず文字だけ。
  - 区分のない教材は、今までどおり式の条件・データの条件の2つの一覧。
  - 見出しの横の数は区分ごと（要件 1・仮定 1 など）。
  - 保証すること・外れたとき（目安なら対象と出典）が同じ行は1つの枠にまとめ、文を並べる（二項分布の4つの仮定で同じ説明を4回出さない。2026-11-08）。
- **原則**：4・7・6・12・8
- **前提**：教材が成立条件の区分（型の改訂38の conditions_detail）を書いた分類。stats2-course #249 の呼び名
- **根拠**：渡辺さん 2026-11-07・08（stats2-course #249 ①④。式を基準の定義にし、定義と「その分布に従う条件」を分ける）
- **見直す条件**：1つの概念の成立条件が10行を超え、区分の中でたたむ必要が出たとき

### 関係のタブの見出しは呼び名と向きで分ける
- **決定**：概念のページの関係のタブは、定義に使う概念・前提知識・前提・変換・対比・これを定義に使う概念・応用の見出しに分ける（使われる側のページは「これを定義に使う概念」）。見出しが種類を言っている行には札を重ねない。つながりの地図（RelMap）は4つの側のまま、側の名前は見出しの名前をつなげて出す
- **原則**：4・8・7
- **前提**：型の種類の名前（材料・前提）は v2 まで変えず、画面の言葉（src/kinds.tsx の kindName）だけを新しくする
- **根拠**：渡辺さん 2026-11-07（stats2-course #249 ④）
- **見直す条件**：つながりの地図を、関係の種類ごとの置き場所で描き直すとき（#249 のあと。渡辺さん 2026-11-07）


### ⑤ の種類は今の画面の種類に読み替える（M6 まで）
- **決定**：型 v2 の公開データの ⑤ の種類（定める・一種・特別な場合・移る・従う・同値・推定する・根拠・導ける・比べる）を、読み込みで今の画面の種類（材料・種類・一般化・変換・応用・導出・対比）に読み替えて描く（src/data.ts の SCREEN_KIND_OF_V2）。元の種類は kind_v2 に残し、札には ⑤ の名前を出す（特別な場合・従う など）
- **原則**：4（同じものはどの入口からも同じ見た目）・8
- **前提**：関係図・地図・学ぶ順の画面は v1 の種類で描く作りで、⑤ で描き直すのは stats2-course の M6（issue 270）
- **根拠**：渡辺さん 2026-11-09（stats2-course issue 289。確率分布を ⑤ に移した教材を公開するため）
- **見直す条件**：画面が ⑤ の種類のまま描けるようになったとき（M6）。そのとき読み替えを外す

### 一種の親は「何の一種か」、子は「この一種」
- **決定**：概念のページの関係のタブで、一種（今の画面では種類）の親は子のページの上の側に「何の一種か」の見出しで、子は親のページの下の側に「この一種」の見出しで出す。見出しが種類を言うので札は付けない
- **原則**：8（応用の側に落ちると「この先で使う」と読める）・17
- **前提**：親の定義は子の定義に入る（製本 ⑤ の包含）ので、定義に使う概念と同じ上の側に置く
- **根拠**：渡辺さん 2026-11-09（二項分布のページで確率分布が応用に出ていたスクリーンショットから）
- **見直す条件**：M6 で関係のタブを ⑤ の種類で組み直すとき
- **同じ考え方**：特別な場合（今の画面では一般化）も、特別な場合のページは上の側に「何の特別な場合か」、一般の側のページは下の側に「この特別な場合」（2026-11-09。幾何分布のページで負の二項分布が応用に出ていた）

### つながりの地図で、同じ相手の点は1つ
- **決定**：つながりの地図（RelMap）で、同じ相手に関係が2本以上（特別な場合と移る、移ると比べる など）あれば、点は1つにして、姿を変える → 比べる → 前 → 後 の順で先の側に置き、ほかの関係は札に並べる（「厳密・特別な場合」）。下の一覧には全部の行を残す。点の残らない側には見出しを出さない。札は線の真ん中ではなく、相手の点の手前に置く（右の点が1つなら点の上）
- **原則**：8（同じものを2か所に置かない）・6（札が中心の近くで重ならない）
- **前提**：製本 ⑤ の 7 で、包含＋移る・比べる＋ほか は同じ組に重ねてよい
- **根拠**：渡辺さん 2026-11-09（二項分布のページでベルヌーイ分布が2つ出ていたスクリーンショットから）
- **見直す条件**：同じ組の関係を1本の線の上で切り替えて見せる形を作るとき

### つながりの地図の1つの側は上限で畳む
- **決定**：つながりの地図の1つの側に置く点は、縦に並ぶ右と左は5つ、横に並ぶ上と下は6つまで。残りは側の見出しに「＋N」と添える（全部は下の一覧にある）。側の見出しは1行に収め（左右は13字・上下は26字まで）、長いときは最初の見出し＋「など」にする（2026-11-09。確率分布のページで見出しが地図をまたいで線に重なっていた）。右と左の5つは間を 31（点の高さ 30 より広く）にする
- **原則**：15・6
- **前提**：確率分布のページでは、一種の子・これを定義に使う概念・応用で左に10を超える点が並ぶ
- **根拠**：2026-11-09（確率分布に7つの分布の一種を足したとき、左の点が重なって読めなくなった）
- **見直す条件**：地図の大きさを変える・側を増やすとき

### 長押しの手触り：沈んで光る
- **決定**：
  - 長押しのある所は全部、押さえている間に同じ手触りを出す：押した物がゆっくり沈み（0.92 倍まで）、縁が主の色で光っていく。満ちたところ（--dur-hold、450ms）で長押しが決まり、軽く振動する。途中で離すとふつうの「押した」。
  - ふつうのタップの間は見えないよう、押した返事（--dur-press）のあとから始める。指を動かしたら（地図を動かす）やめる。
  - 線は沈まず、太くなりながら光る。
  - 仕組みは math-lab の base.css の `data-hold`（見た目の物が子のときは、その子に `data-hold-part`、押す物に `data-hold-on-part`。子があるかを `:has()` で見ない。WebKit で止まる疑い。stats2-course #285）。新しく長押しを足すときも、これを付ける（tests/e2e/hold.spec.ts）。
  - 動きを減らす設定では沈まず、満ちたときに縁を一度灯すだけ。
- **原則**：10・13
- **前提**：長押しは見えない操作で、押さえている間に「長押しになる」と分からないと、離してよいか迷う
- **根拠**：渡辺さん 2026-11-07（戻るの長押しの見本 https://claude.ai/artifact/N4NgvkERR9KnRSJ5E9K5M4 で「3 沈んで光る」。「その他の長押しエフェクトにも統一が必要」）
- **見直す条件**：長押しの長さが合わない（早すぎて誤って出る・遅すぎて待たされる）と分かったとき

## ラボと作業台

- **決定**：

  - 作業台の入力の帯も同じ手触り（math-lab の CLAUDE.md「作業台の型」）。
- **原則**：17・19・1
- **前提**：iPhone の幅で、ラボ・作業台の値を変える

- **見直す条件**：値を同時にいくつも見比べる必要が出たとき

### 式を開く・戻る（作業台の主役の式）
- **決定**：
  - 開く：選んだかたまりに開ける関数（ₙCₖ・k! など）があるときだけ、かたまりの囲みの右上の角を小さく折り返す（11px の三角・主の色・囲みと同じ角の丸み。中にもう1枚ある、の見立て。押せる所 44px は角を中心に上へ出し、横は角から 8px までにして隣のかたまりにかけない）。押すとその場で定義の式に開く。開く形が2つ以上なら、折り返しで帯に形の名前（原本の式の label）を出して選ぶ。
  - 帯には、開く操作を置かず、入口の1行（「右上の折り返しで『階乗で表す』に開く」）だけを置く。定義の長い等式はボタンに載せない（開いたあとの式そのものが見せる）。
  - 戻る：式のすぐ上に「元の式 › 組合せ › 階乗」（概念の名前。前の段を押すとその段まで戻る）と、右端に「一段戻る」。一段戻るは開いた数・式の高さで動かない。前の「たたむ」（帯と式の下の2か所）と「元の式に戻す」は、この道に置き換えた。

### 期待値の実験室：全部の値を a 倍して b 足す（C-01。開く先 linear）
- **決定**：テーマごとに、元の表と変え方（型の改訂11の `linear`：a・b・change）を並べ、a・b に言葉を添える（b が負なら「引く」）。`linear` のないテーマは出さない。予測は1つの三択「こう変えると、何度も引いた平均の行き先（期待値）は？」で、選び肢はよくある取り違えから作った具体の数（a×m＋b・a×(m＋b)・a×m）を小さい順に並べる。照らすのは予測だけ（理論から決める）。実験は元の表から引き、変えた値は同じ引きを a 倍して b 足して写す。観察は 平均（引いた）・期待値 を元の値と変えた値で並べ（3列）、見る所は「変えた値の列で、平均と期待値を見比べる」だけ。「a×元の引いた平均＋b」の等式は、作り方から決まるので観察では出さず、考察で Σ(ax＋b)p＝aΣxp＋bΣp と並べて言う。頻度は「マスが目安の外に出るのは約5%。2マスは同じ引きから作るので、外に出るときは一緒に出る」（A-03 の「どちらかが最大で」は写さない）。段は 予測・実験・観察・考察（応用があれば応用）
- **原則**：1（触っていない間に変えない）・4（考察の展開は期待値と同じ部品 TableReason）・7（元の値・変えた値は名前で呼ぶ）。在り方「予測してから確かめる」
- **前提**：a＞1 なら a×m＋b はいつも a×m と a×(m＋b) の間に来るので、全部のテーマが a＞1 だと正しい答えがいつも真ん中になり、位置で当たる。テーマの a・b を替えて正しい答えの位置を変える（教材の build が、全テーマで位置が同じなら止める）。ずれの目安の幅が a 倍になる理由（V(aX＋b)）は散らばりの発見なので、観察では数だけを出す（⑦ の監査役の独立なレビュー 2026-11-15）

### 期待値の実験室：値段を払って引く（E-01。開く先 price）
- **決定**：テーマごとに、表と1回あたりの値段（型の改訂12の `price`：c・word・change）を並べる。値段の呼び名はテーマごとに持つ（くじは値段、さいころは参加費）。`price` のないテーマは出さない。単位のないテーマ（さいころ）も、この問いではもらえる額として円で数える。予測の段では期待値を見せない（期待値で決まること自体が発見）。予測は三択「この値段で何度も引くと、1回あたりの損得の平均は？（平均で得／ちょうど損得なし／平均で損）」。照らしは理論の値と向きだけで、理由（期待値−値段の引き算）は言わない。観察へは 1000 回から進む。観察は 損得の平均（1回あたり）・損した回の割合 を、引いた値と理論で並べる（3列）。損した回は、もらえる額が値段より小さい回で、同じ額は入れない。ずれの目安を2行とも出し、頻度は「得と損が逆に出る（正規近似のおおよそ）」と「2行のどちらかが外に出るのは最大で約9.8%」。考察は損得の表を値×確率の項に開き、変換の式は C-01 へ、まれな大きい額の効き方は A-03 へ、開ける問いだけを題つきで案内する。段は 予測・実験・観察・考察（応用があれば応用）
- **原則**：1（触っていない間に変えない）・4（考察の展開は期待値と同じ部品 TableReason）・7（値段・参加費を名前で呼ぶ）。在り方「予測してから確かめる」
- **前提**：100 回で観察へ進むと、くじは得なのに損得の平均が負に出るのが約31%（厳密値）ある。考察で E(X−c)＝E(X)−c と言うと C-01 の発見を先に言い、「同じ期待値でも表が違えば損する割合が変わる」と言うと D-01 の発見を先に言う（⑦ の監査役の独立なレビュー 2026-11-15）。ⓘ のシートは式に値を入れて出すので、予測の前でも期待値が見える。これは助け（自分で開く）として許す（A-02 と同じ）
- **根拠**：渡辺さん 2026-11-14（手順はお任せ。計画の手順1）。案は ⑦ の監査役の独立なレビューの指摘を全部取り込んで直した
- **見直す条件**：iPhone で確かめて分かりにくさが出たとき。ⓘ のシートで予測する量を隠すと決めたとき
- **追記（2026-11-15。学習者役のレビュー。#401 の型7・10）**：考察の見出しはテーマに依らない形（「損した回の割合と、平均の損得は別」。さいころでは平均で損なので「平均では得？」が逆になった）。題の問い「いくらまでなら得？」に考察で答える（値段が期待値より小さければ平均で得・等しければ損得なし・大きければ損）。損した回の割合の目安は「ポイント（割合の % の差）」と言う

### 期待値の実験室：打ち切りを変えた倍々のくじ（B-01。B-02 をまとめた。開く先 lln）
- **決定**：反例の欄の倍々のくじを、打ち切り（型の改訂13 の `cutoffs`：10・20・40 回）で切り直す（k＜K の重みは 2^(K−k)、k＝K は 2）。予測の段では打ち切り 20 回の表と期待値（21 円）を見せ、「1000 回引いた平均は、期待値より下・上・同じくらいのどれが多いか」の三択。照らしは、決まった種で 1000 回の実験を 2000 組くり返して求めた「期待値より下に出る割合」（約 84%）で決める（0.6 より上なら下、0.4 より下なら上、ほかは同じくらい）。実験は3つの打ち切りを 1000 回ずつ別々の種で引き、3つとも引くと観察へ進む。観察は 期待値・引いた平均 を打ち切りごとに並べ、ずれの目安は有効数字2桁（万・億・兆）。「約95% が入る」は正規分布に近い打ち切り 10 回のときだけ言い、チェビシェフ（分散が有限なら 25% 以下）を添える。頻度は3つの打ち切りの「期待値より下に出る割合」。考察は、項がどれも 1（打ち切りをなくすと期待値は有限でない）、期待値の大半をまれで巨大な額が支える（1000 回で 2¹¹ 円以上・2¹⁵ 円以上を引く確率）、近づく先と目安が使える条件（期待値が有限・分散が有限）の3つ
- **原則**：1（触っていない間に変えない）・2（打ち切りは押して選ぶ）・7（打ち切りを名前で呼ぶ）。在り方「予測してから確かめる」
- **前提**：重い裾では標本平均の分布が正規分布に近くなく、±2×標準誤差に約95% が入るとは言えない（打ち切り 20 回で 98.5%、40 回で 100%）。食い違って見えるのは向き（平均がたいてい期待値より下）なので、向きの頻度を、正規近似でなく決まった種のくり返しで出す（engine の meanBelowShare）。「期待値が有限なら近づく」は教材の主張（CLM-20b：分散が有限）を越えるので、近づく先の条件としてだけ言う。同じ種で3つの打ち切りを引くと、20 回と 40 回の平均がほぼいつも同じ数になる（⑦ の監査役の独立なレビュー 2回・スクリーンショット 2026-11-15）
- **根拠**：渡辺さん 2026-11-14（B-01 と B-02 をまとめる案1。手順はお任せ）。案は ⑦ の監査役の独立なレビュー 2回の指摘を全部取り込んで直した
- **見直す条件**：iPhone で確かめて分かりにくさが出たとき。打ち切りの数を変えるとき（照らしの境目 0.4・0.6 を見直す）
- **追記（2026-11-15。学習者役のレビュー。stats2-course #401 の型8・9・11）**：予測は頻度（下に出ることが多いか）なのに、実験が各打ち切り 1000 回の1組だけで、学習者が自分の実験で「多い」を確かめられなかった。1組＝1000 回とし、打ち切りごとに 5 組引いて「期待値より下に出た組」を数える（予測と同じ粒度）。打ち切りは「投」で数える（1000 回引く の「回」と分ける）。目安が使える条件（正規分布に近い・チェビシェフ）は観察から考察へ移した。考察の条件は TERM-lln にそろえて「分散が有限なら近づく」（2回目の監査で judge だけ直し、画面の文に「期待値が有限なら」が残っていた）。裾の文は「2¹⁵ 円以上が 27 円分を担い、1組で引くのは約 6%」の1文にした（62% を見せると「まれ」と読み違える）

### 実験と理論の照らしの桁（stats2-course #200。2026-11-18）
- **決定**：
